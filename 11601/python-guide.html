print()｜讓電腦說話

🐱 Scratch：說 ___

print() 把括號裡的內容顯示出來。文字要放在引號中。

print("歡迎來到高雄")
print("今天要去散步")

變數｜讓電腦記住資料

🐱 Scratch：變數積木

變數像有名字的盒子。等號右邊的資料會被放到左邊的變數。

city = "台南"
days = 2
print(city, days)

這是不同情境的語法示範。理解後回闖關頁完成自己的任務。

input()｜詢問並取得回答

🐱 Scratch：詢問 ___ 並等待

input() 會顯示問題並等待輸入。通常把回答存進變數。

drink = input("你想喝什麼？")
print(drink)

這是不同情境的語法示範。理解後回闖關頁完成自己的任務。

int()｜把輸入轉成整數

🐱 Scratch：輸入後拿去做整數計算

input() 得到的是文字；需要整數運算時，可用 int()。

age = int(input("年齡："))
print(age + 1)

這是不同情境的語法示範。理解後回闖關頁完成自己的任務。

運算｜+ - * / // %

🐱 Scratch：運算積木

// 是整除，% 是餘數。

print(19 // 4)   # 4
print(19 % 4)    # 3
print(6 * 7)     # 42

這是不同情境的語法示範。理解後回闖關頁完成自己的任務。

float()、**、round()｜小數與次方

🐱 Scratch：數學運算

float() 處理小數；** 算次方；round() 整理小數位數。

x = float(input("輸入小數："))
answer = x ** 2
print(round(answer, 2))

這是不同情境的語法示範。理解後回闖關頁完成自己的任務。

if / else｜如果…否則

🐱 Scratch：如果／否則

條件後面要有冒號，分支內的程式要縮排。

temperature = 30
if temperature >= 28:
    print("很熱")
else:
    print("還好")

這是不同情境的語法示範。理解後回闖關頁完成自己的任務。

elif｜處理三種以上情況

🐱 Scratch：多層如果／否則

elif 是「否則如果」。

score = 75
if score >= 90:
    print("A")
elif score >= 60:
    print("B")
else:
    print("C")

這是不同情境的語法示範。理解後回闖關頁完成自己的任務。

and / or｜組合兩個條件

🐱 Scratch：且／或

and：兩邊都成立。or：至少一邊成立。

sunny = True
free = True
if sunny and free:
    print("去公園")

這是不同情境的語法示範。理解後回闖關頁完成自己的任務。

for / range()｜按照規律重複

🐱 Scratch：重複指定次數

range(start, stop, step) 可設定開始、停止前的位置和步進。

for n in range(1, 6):
    print(n)

for n in range(6, 0, -1):
    print(n)

這是不同情境的語法示範。理解後回闖關頁完成自己的任務。

while｜條件成立就繼續

🐱 Scratch：重複直到

while 會在條件為 True 時持續執行。記得讓條件有機會改變。

count = 1
while count <= 4:
    print(count)
    count = count + 1

這是不同情境的語法示範。理解後回闖關頁完成自己的任務。

random｜產生隨機整數

🐱 Scratch：在兩數間隨機取數

先匯入 random，再用 randint(a, b)。

import random
card = random.randint(1, 13)
print(card)

這是不同情境的語法示範。理解後回闖關頁完成自己的任務。
